# 陸行鳥大賽 3D — 架構說明

一個用 three.js 即時渲染的騎乘鳥類賽車模式，網址 `/race`。
賽道、座騎、場景全部由程式產生，沒有任何外部模型或貼圖檔，
整包 gzip 後約 19 KB（three.js 另外切成共用 chunk）。

```
src/game/race/
  core/
    types.ts     所有共用型別
    track.ts     Catmull-Rom 賽道：重採樣、投影、格位、彎度查詢
    physics.ts   單隻鳥的運動模型（油門、甩尾、體力、碰撞）
    ai.ts        對手駕駛：瞄準前方、過彎降速、衝刺與甩尾判斷
    race.ts      RaceSim：比賽狀態機、圈數、名次、事件
    records.ts   localStorage 最佳成績
  data/
    birds.ts     6 種座騎的數值與配色
    tracks.ts    3 條賽道的控制點與調色盤
  render/
    birdRig.ts     用基本幾何體組成的陸行鳥骨架與跑步動畫
    trackScene.ts  路面、路緣石、草皮、加速板、看板、場景物件
    RaceRenderer.ts 場景管理、追尾攝影機、塵土粒子

src/components/game/race/
  RaceSetup.tsx  選座騎／賽道／難度的大廳
  RaceView.tsx   canvas、遊戲迴圈、鍵盤與觸控輸入
  RaceHud.tsx    速度表、名次、體力／蓄力條、小地圖、結算畫面

src/pages/ChocoboRace.tsx  路由頁面（在 App.tsx 以 lazy 載入）
```

## 賽道

`buildTrack()` 把十來個控制點做成封閉的 Catmull-Rom 曲線，再以固定弧長
（約 1.6 單位）重新採樣。每個採樣點都帶有切線、法線、曲率、傾斜角與該處的
路寬，之後所有東西都讀這份資料：

- 路面網格直接由採樣點拉成一條 ribbon，路緣石與草皮是同樣做法的單側版本。
- `project(x, z, hint)` 用上一幀的採樣索引當提示，只掃描附近的窗口，
  所以每隻鳥每幀都是 O(1)；跳太遠時會自動退回整圈掃描。
- AI 的過彎減速讀 `curvatureAhead()`。

新增賽道只要在 `data/tracks.ts` 加一組控制點與調色盤，其餘全部自動生成。

## 物理

刻意做成街機手感，而不是模擬：鳥永遠沿著 `moveYaw` 前進，而 `moveYaw` 會以
抓地力決定的速率追上朝向 `yaw`。按住甩尾會把抓地力砍到約三成，於是車頭與行進
方向分離產生滑行，同時累積蓄力；放開時依蓄力給 0.65／1.15／1.75 秒的加速。
滑行角度愈大，極速的懲罰也愈大，所以亂甩並不會比較快。

其他資源：

- **體力**：按住衝刺每秒消耗 26，極速 +16%；放開會回復，出界時回復變慢。
- **加速板**：每圈每塊只吃一次，給 1.15 秒加速與 18 點體力。
- **出界**：極速掉到 62%、阻力加倍；再往外 6.5 單位有一道軟牆會把鳥推回來。

## 圈數判定

名次用的是單調累加的 `progress`（每幀加上弧長差），所以打滑、倒車、停在線上
都不會讓排名亂跳。圈數則靠「跨線 + 半圈檢查點」兩個條件：起跑格排在起跑線
後面，所以開賽後的第一次跨線只是起跑（同時開始計算第一圈的時間），
倒車來回輾過終點線也不會刷圈。

## 對手

`driveRacer()` 讓對手瞄準前方 `9 + 速度×0.55` 單位處，並依照即將到來的曲率
把目標點往彎內偏。過彎速度上限用 `sqrt(側向抓地力 / 曲率)`，抓地力由座騎的
grip 與 handling 決定，所以靈活的鳥真的能用比較快的速度過彎。

難度只調整一個 `skill` 值（輕鬆 0.62／標準 0.76／高手 0.90），它同時影響
路線的抖動、過彎極限、直線油門，以及會不會用衝刺與甩尾加速——
輕鬆的對手兩樣都不會用。另外有很輕微的橡皮筋效果拉住落後的對手。

## 測試

`src/game/race/core/*.test.ts` 用 vitest 跑純模擬（不需要 WebGL）：
賽道重採樣的均勻度與投影正確性、起跑格、倒車不算圈、完整比賽的圈速範圍、
名次與完賽順序一致、相同種子的結果可重現，以及體力／甩尾／碰撞的行為。

```sh
npm test -- src/game/race
```
